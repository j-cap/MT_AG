# Report structure

The repository now maintains two LaTeX entry points with different purposes:

- `main.tex` — **detailed research report**. This is the full research record: experiment protocols, parameter choices, negative results, reproduction decisions, limitations, and backlog.
- `summary_main.tex` — **condensed research summary**. This contains only the scientific chain needed to understand the current project state and the transition to the next phase.

Both documents deliberately reuse the same material under `report/figures/`. There is no separate summary-figure directory.

## Phase-1 figures

Each Phase-1 experiment in the detailed report now contains a result visualization near its experiment text. The condensed report references only the subset needed for the main scientific story.

Figures are generated by:

```bash
python experiments/generate_report_figures.py
```

The generator reads version-controlled result extracts / summaries and writes PDFs to `report/figures/phase1/`.

## Editing rule

Use the detailed report for evidence and provenance. Use the condensed report for the current scientific narrative.

When a new experiment is added:

1. document the full protocol and evidence in `main.tex` / the detailed sections;
2. add or update one reproducible figure when it materially helps interpretation;
3. update `summary_main.tex` only if the result changes the project-level scientific story;
4. reuse the same figure file in both reports when appropriate.
