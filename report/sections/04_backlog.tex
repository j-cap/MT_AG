\chapter{Research Backlog}
\section{Phase 1 completion criteria}
Phase 1 is complete only after the following sequence is documented and reproducible.
\begin{enumerate}
    \item \textbf{P1A -- IMU baseline:} deterministic planar IMU mechanization, noisy inertial drift, Gaussian UWB measurement, and conventional PF correction. Current status: \textbf{completed}. The implementation is verified and the result is supported by the P1B multi-seed study.
    \item \textbf{P1B -- robustness of the known-pose baseline:} multi-seed study; sensitivity to initial position/velocity/yaw uncertainty; particle count; IMU noise and bias levels; PF process-noise sensitivity. Current status: \textbf{completed and documented}. The known-pose PF improves position RMSE in all 20 baseline seeds, while large initialization errors and persistent IMU bias have been identified as explicit boundaries for later work.
    \item \textbf{P1C -- unknown initial pose:} introduce the global-localization problem using a first-range-conditioned position ring and globally distributed yaw hypotheses. Make the initial velocity prior explicit for the IMU-driven state. Current status: \textbf{completed as a diagnostic phase}. The known-yaw control is largely recoverable, whereas the realistic unknown-position/yaw bootstrap PF converges in only 2/20 core runs. Increasing particle count or disabling resampling does not resolve the failure. An idealized 40000-particle check with exact IMU/UWB information converges in 3/3 runs, showing that the selected moving-auxiliary scenario can resolve the ambiguity under ideal information.
    \item \textbf{P1D -- geometry/observability:} compare stationary, degenerate constant-bearing, and informative moving auxiliary trajectories; report convergence, particle-cloud behaviour, and finite-horizon observability singular values. Current status: \textbf{completed and documented}. The stationary single auxiliary has numerical rank four, the constant-bearing construction rank three, and only the informative moving auxiliary reaches full rank five. The two rank-deficient cases achieve no full-pose convergence in either realistic or idealized filtering, while the moving case is the only geometry with successful recovery. Realistic moving-case success is nevertheless only 5/20, showing that full local observability is necessary but not sufficient for robust bootstrap-PF global localization.
    \item \textbf{P1E -- paper reproduction audit:} document each equation and algorithmic step of Han et al.; list every underspecified AACOPF parameter and the chosen interpretation. Distinguish the paper's $\Delta L,\Delta\psi$ DR interface from the thesis IMU-driven mechanization. Current status: \textbf{next task}. The audit must distinguish geometry-induced non-observability from particle-approximation failure in an informative geometry.
    \item \textbf{P1F -- AACOPF implementation:} implement the audited transition/resampling mechanism and compare conventional PF and AACOPF on matched trajectories/noise realizations. The P1C/P1D informative moving case should be included as a principal challenge case; rank-deficient cases should be retained as negative controls rather than as situations in which AACOPF is expected to create observability.
\end{enumerate}

\section{Current Phase-1 parameter decisions after P1D}
For the local known-pose experiments, the P1B conclusion remains valid: $N_p=5000$ particles is a conservative default, and $N_p=2500$ is acceptable for exploratory sweeps. The P1A PF process-noise values are retained because P1B shows similar performance for the baseline and a $2\times$ scaling, whereas substantially smaller process noise causes under-dispersion and occasional failures.

The global-pose problem requires a different interpretation of particle count. A structured $100\times100$ position/yaw grid ($N_p=10000$) is retained as the practical global-search baseline for realistic matched diagnostic experiments. P1C showed that increasing this grid to $150\times150$ did not make convergence reliable. The idealized $200\times200$ ($N_p=40000$) configurations are therefore diagnostic tests of representability/identifiability rather than practical defaults.

P1D establishes that geometry must be treated before particle-algorithm tuning. The stationary single-auxiliary and constant-bearing cases are rank deficient and therefore serve as negative controls: no particle-transition strategy should be interpreted as solving the missing-information problem in those geometries. The informative moving case is full rank but remains difficult for the bootstrap PF; this is the appropriate principal case for testing whether AACOPF improves preservation and selection of competing global modes.

Persistent accelerometer/gyroscope bias remains an open estimator-design question rather than an immediately added state. The P1B stress test shows that unestimated bias can dominate the remaining error, but the selected stress levels are synthetic. The decision to augment the state with bias variables should therefore be made after real IMU bias/noise characteristics are available.

The initial velocity assumption also remains explicit. P1C shows that free initial velocity substantially worsens the global search. The aligned fixed-speed prior is therefore retained through the Phase-1 geometry and algorithm-reproduction studies so that the separate initial-velocity problem is not confounded with observability and particle management. Later hardware-oriented work must justify how initial speed or velocity direction is obtained in the intended application.

\section{Decision required during paper reproduction}
The important modeling distinction is how closely the paper reproduction and the IMU-driven thesis implementation should be coupled. Two clean options are available:
\begin{description}
    \item[Option A -- two baselines:] reproduce Han et al. with the original $[p_x,p_y,\psi]$ state and $\Delta L,\Delta\psi$ interface, while maintaining the IMU-driven $[p_x,p_y,v_x,v_y,\psi]$ estimator as the hardware-oriented thesis baseline. This is scientifically cleanest for separating reproduction from adaptation.
    \item[Option B -- adapted reproduction:] implement AACOPF directly around the IMU-driven state model. This is closer to the final hardware but makes direct comparison with Han et al. less faithful.
\end{description}
The current recommendation remains Option A, followed by a documented transition from the paper baseline to the IMU-driven implementation. P1C strengthens this recommendation because the added velocity states introduce an initialization issue that does not exist explicitly in the paper's higher-level DR interface. P1D adds a second requirement: any AACOPF comparison must state whether the tested geometry is observable before attributing success or failure to the particle algorithm.

\section{Phase 2--4 outlook}
Phase 2 will vary UWB update rate, node count, geometry, outages, LOS/NLOS degradation, and IMU quality. P1D already establishes the principle that range count alone is not a sufficient measure of localization information; Phase 2 should therefore retain geometry descriptors when comparing communication rates and node-selection strategies. Phase 3 will develop uncertainty/information-aware UWB scheduling and node selection. Phase 4 will characterize the actual hardware, replace simulated sensor parameters with measured ones, measure energy per UWB transaction, port the selected estimator to C/C++, and compare simulation and hardware.
