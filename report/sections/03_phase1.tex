\chapter{Phase 1: Baseline Reimplementation and Understanding}
\section{Purpose}
Phase 1 is intended to create a trustworthy baseline before investigating communication efficiency. The first milestone is deliberately easier than the full problem in Han et al.: the target starts from an approximately known state, UWB noise is Gaussian, and the auxiliary-node trajectory is known. This isolates the inertial propagation and range-fusion logic. The unknown-initial-pose problem and AACOPF are introduced only after this baseline is verified.

\section{Experiment P1A: IMU-based DR and UWB correction}
\subsection{Hypotheses}
The current verification experiment tests four qualitative statements:
\begin{enumerate}
    \item ideal IMU mechanization reproduces the deterministic reference trajectory exactly under the shared discrete model;
    \item noisy accelerometer and gyro measurements produce accumulated DR error;
    \item a conventional bootstrap PF using UWB ranges can substantially reduce position drift;
    \item auxiliary-node motion changes the information content/observability of the range sequence.
\end{enumerate}
No claim of statistical superiority is made from a single random seed.

\subsection{Deterministic motion}
The simulation lasts \SI{60}{s} with sample time \SI{0.1}{s}. The initial state is
\begin{equation}
\bm{x}_0=[0,0,0.75,0,0]^\top.
\end{equation}
A smooth body longitudinal acceleration and yaw-rate profile are prescribed,
\begin{align}
a_x^b(t) &= 0.018\sin(0.14t)+0.006\cos(0.05t),\\
\omega_z(t) &= 0.055+0.025\sin(0.07t).
\end{align}
For the nominal forward-motion trajectory the lateral body acceleration is selected as
\begin{equation}
a_y^b(t)=v(t)\omega_z(t),
\end{equation}
which provides the centripetal acceleration associated with the turning motion. The trajectory is propagated with the inertial mechanization defined in the previous chapter.

\subsection{Auxiliary-node trajectories}
The stationary diagnostic uses an auxiliary at $(8,-4)$ m. The moving auxiliary follows
\begin{equation}
\bm{a}(t)=
\begin{bmatrix}
8-0.10t\\
-4+0.22t+1.2\sin(0.08t)
\end{bmatrix}.
\end{equation}
The specific curves are not intended to represent a final application scenario. They provide controlled geometries for debugging and for checking the expected stationary-versus-moving observability distinction.

The revised IMU implementation was executed locally with the committed configuration and passed five unit/integration tests. The resulting metrics are shown in Table~\ref{tab:p1results}.

\midrule

The position RMSE reduction relative to noisy DR is approximately
\begin{equation}
1-\frac{0.231}{1.378}\approx 83.2\%.
\end{equation}
This number demonstrates that the implemented UWB likelihood is able to pull the position estimate back toward the correct trajectory in this controlled realization. It is not yet evidence for a general expected improvement because only one trajectory, noise realization, update rate, and particle configuration have been evaluated.

\section{Interpretation of the heading result}
The PF heading RMSE is larger than the heading RMSE of the direct noisy-IMU DR in this particular run. This result is intentionally retained. A scalar range does not directly observe heading. Heading can only be inferred indirectly through the time evolution of the range under motion. The PF also introduces initial heading spread and process perturbations. Therefore Phase 1A currently supports the statement that UWB corrects \emph{position drift}; it does not yet support a claim that the chosen PF improves yaw estimation. Unknown-pose localization and heading convergence must be assessed explicitly in the later observability/convergence experiments rather than inferred from this debugging case.

\section{Observability diagnostic}
For the five-state IMU-driven model, the stationary auxiliary yields singular values approximately
\begin{equation}
(931.97,\;232.84,\;49.46,\;7.05,\;4.12\times10^{-14}),
\end{equation}
which is numerically rank deficient. For the selected moving auxiliary the singular values are approximately
\begin{equation}
(916.48,\;320.81,\;45.58,\;8.05,\;0.602).
\end{equation}
Thus the moving case is full rank for this local finite-horizon linearization, although its smallest-to-largest singular-value ratio is only about $6.57\times10^{-4}$. The result is consistent with the geometric argument that a moving, globally known auxiliary trajectory can break the rotational symmetry of a single stationary range reference. It does not by itself prove global nonlinear observability.

\section{What changed relative to the first repository bootstrap}
The original code corrupted $\Delta L$ and $\Delta\psi$ directly. That was useful as a rapid check of the Han et al. high-level model, but it bypassed the central source of inertial drift. The revised implementation now follows
\begin{equation}
\boxed{\text{accel. + gyro measurements} \rightarrow \text{inertial mechanization} \rightarrow \text{DR state} \rightarrow \text{UWB/PF correction}}.
\end{equation}
This is the preferred baseline for the thesis hardware direction. The earlier increment-level numerical result should therefore be treated as superseded by the IMU-based verification result above.

\section{Known limitations of P1A}
The following limitations are deliberate and must be removed or investigated before Phase 1 is complete:
\begin{itemize}
    \item level 2-D motion and gravity-compensated horizontal accelerations;
    \item approximately known initial position, velocity, and yaw;
    \item no explicit accelerometer/gyro bias state in the PF;
    \item UWB at every simulation step with Gaussian noise only;
    \item one deterministic target trajectory and one random seed;
    \item no packet loss, NLOS bias, or clock/timing effects;
    \item no AACOPF particle-transition mechanism yet;
    \item no measured ESP32/IMU/DW3000 sensor parameters yet.
\end{itemize}
